How does an AI answer? Watch a real one, one step at a time.

It's autocomplete: a language model guesses the next word, adds it, and guesses again. Here a real one runs in your browser, slowed down so you can follow every step. Every number you see is its own.

A language model is autocomplete: it only ever guesses the next word. An "AI agent" is that model plus a short program that people wrote. The model can only write words. The program gives it a task, reads what it writes, and when the words are a command, types that command into a shell (the box where people type commands to a computer), then gives the output back for the model to read. Round and round. That loop is all "autonomous" means. Here is a real one, slowed down so you can follow every step. It is the same model machinery as in Write mode, plus the steps marked agent.

1Your words become pieces

Looking back at an earlier step. Press Continue to return to where you were.

The picture: a big list of pieces, each with a number. The list was built before training by finding the most common chunks of text, so common words are one piece and rare words are several. Every model has its own list, of its own size (GPT-2's has 50,257 pieces, Qwen2.5's 151,936), so the same sentence becomes different numbers in each; the idea is the same. The model never sees letters: only these numbers, which in memory are bits, 0s and 1s, like everything else in a computer.

2Each piece gets its spot in the cloud

Looking back at an earlier step. Press Continue to return to where you were.

Your pieces, each at its spot in the cloud.

The picture: a cloud with one dot for every piece in the dictionary. A piece's list of numbers is its address in the cloud, and pieces used alike sit close together: it comes from how a word is used, not how it sounds. The real cloud has one direction per number (from 128 to 768 in these models); the map squashes it flat, so distances on it are rough.

The knobs

Its numbers, before and after this layer

The picture: rows of volume knobs, set at the factory and glued. Before each row, the newest word listens back to the earlier words (pink) and blends in what matters. That listening is the only step whose mixing depends on what you type.

4Through every layer

Looking back at an earlier step. Press Continue to return to where you were.

The thought cloud: every piece in the dictionary is a dot, and pieces used alike sit close together.

The picture: the same thing, row after row of knobs. Next to each layer: what it would say if it stopped there (the “logit lens”), and in the cloud, every piece it might say lights up. Early layers are not built to be read this way, so their guesses look odd. The guess after each layer is a peek we take by running the model's final scoring early: the model itself only scores once, after the last layer, and never looks anything up in between. The cloud is a flat map of the model's own embedding rows (made with t-SNE); distances on it are approximate.

2The hidden instructions agent

Looking back at an earlier step. Press Continue to return to where you were.

Before your task, the program puts text you never see in front of it: the system prompt. Apps do this too. Here it has three parts:

Why does a bit of text make it use a shell? Test it.

The text does not switch anything on inside the model: the 494 million knobs are the same with or without it. It is just more tokens to read. It works because, after its first training on ordinary text, the Qwen team trained this model further on example conversations, and Qwen publishes exactly this chat form and tool format for it (the training data itself is not published). So when the model reads this pattern, a <tool_call> becomes a likely next token, and when it writes the tool's name it reads the list through attention (the arcs reach into the green squares).

The test: run the same task with parts of the hidden instructions removed, and see what the real model does. Each row runs the model from scratch (a few seconds each).
