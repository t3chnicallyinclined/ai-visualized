Watch an AI agent work, step by step. Or try to make it go rogue.

A language model is autocomplete: it only ever guesses the next word. An "AI agent" is that model plus a short program that people wrote. The model can only write words. The program gives it a task, reads what it writes, and when the words are a command, types that command into a shell (the box where people type commands to a computer), then gives the output back for the model to read. Round and round. That loop is all "autonomous" means. Here is a real one, slowed down so you can follow every step.

A real model trained to ask for tools: 494 million knobs (about 358 million in its 24 layers, 136 million in its table of token rows). It runs in this browser tab on your processor, so it needs a computer with a few GB of free memory, not a phone. It downloads once; nothing you type is sent anywhere. The shell is pretend: three files on this page, and no internet.

Before your task, the program puts text you never see in front of it: the system prompt. Apps do this too. Here it has three parts:

Why does a bit of text make it use a shell? Test it.

The text does not switch anything on inside the model: the 494 million knobs are the same with or without it. It is just more tokens to read. It works because, after its first training on ordinary text, the Qwen team trained this model further on example conversations, and Qwen publishes exactly this chat form and tool format for it (the training data itself is not published). So when the model reads this pattern, a <tool_call> becomes a likely next token, and when it writes the tool's name it reads the list through attention (the arcs reach into the green squares).

The test: run the same task with parts of the hidden instructions removed, and see what the real model does. Each row runs the model from scratch (a few seconds each).
